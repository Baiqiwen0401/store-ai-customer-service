# 个体门店 AI 客服

面向美容、美甲、宠物、健身等个体门店的可配置、可记忆、可人工接管 AI 前台客服。

## 当前版本

- 分支：`feature_v1`
- 阶段：首家试点门店 MVP 基线
- 首期入口：网页客服；企业微信接入预留
- 核心能力：门店知识库、客户长期记忆、标准问答、预约意向、人工接管、店主纠错闭环

## 产品原则

```text
模型负责理解与建议
规则服务负责校验
业务系统负责真实执行
人工负责风险与例外
```

首期不将个人微信模拟操作、小红书全自动私信、自动退款和未经审核的模型自训练作为生产能力。

## 方案文档

完整技术方案见：

- `个体门店AI客服技术方案_v1.0.docx`

文档包括总体架构、客户交互、长期记忆闭环、工具调用、数据模型、安全合规、七日计划和 MVP 验收标准。

## 计划中的 MVP 模块

```text
web-chat/       网页聊天组件与咨询页
api/            会话、客户、记忆和门店配置 API
knowledge/      门店资料上传、解析、检索与版本管理
memory/         客户记忆抽取、审核、检索与删除
workflow/       预约意向、人工接管、通知和审计
admin/          门店后台与会话工作台
deploy/         Docker Compose、反向代理、备份和监控
```

## 开发约束

- 所有业务数据按 `tenant_id` 隔离。
- AI 不直接写入订单、退款、发货等高风险业务数据。
- 客户长期记忆必须可查看、修改和删除；候选记忆需经过规则检查，门店知识需审核发布。
- 涉及过敏、疾病、孕期、医疗美容、投诉、退款和纠纷时必须转人工。
- 优先使用官方平台 API；渠道适配器与 AI 核心解耦。
